Divvy departures and directed lag forecasts

The bundled workflow counts observed departures between training-selected geographic origin and destination cells in Chicago. The six-month paper analysis instead assigns trips to links along inferred shortest paths. A saved projected panel can be supplied separately.

Run scope. The smoke run contains 6 directed series and 96 time bins, with 16 final bins reserved for sequential forecasting. These scores check the workflow on the sample and are unsuitable for ranking methods in the manuscript.

Reproduce from the repository root

Install the optional Python dependencies for Graph WaveNet as described in the GLS paper README. Set RESULTS to an external directory on the data or SSD volume. Preparation writes the count panel, source checksums and an exploratory plot. The application runner fits the training window, selects on validation, scores the held-out window and saves compact outputs. Report mode exports individual forecast cells and diagnostics. The final command rebuilds the executive report without fitting.

Rscript GLS-paper/applications/divvy/prepare.R --output="$RESULTS/divvy-prepared.rds"
Rscript GLS-paper/applications/run.R --action=run --profile=smoke --benchmarks=pnar1,pnar2,sa-pgss,graph-wavenet --input="$RESULTS/divvy-prepared.rds" --output="$RESULTS/divvy"
Rscript GLS-paper/applications/run.R --action=report --output="$RESULTS/divvy"
Rscript GLS-paper/reports/render.R divvy "$RESULTS/divvy"
