Recovering time-varying directed effects

A directed road grid supplies known lag coefficients and a broad candidate dictionary. The design crosses the location of the active sources with static or dynamic coefficients. The continuous GLS fit and its validation-selected DSS projection share a posterior.

The grid generator calibrates the lag contribution on separate pilot counts. If its initial scale causes unstable rates or misses the target RMS by more than 2%, the generator searches a bracket of scales on the same pilot draws. The fitted methods receive a fresh evaluation panel generated at the fixed scale.

Shared synthetic datasets

The GLS arm fits graph-informed, static and constant-affinity GLS. The competitor arm fits the all-pairs Poisson lasso. Both arms read the same saved counts and chronological split for each condition and replicate. The full study uses 50 independent replicates per condition.

Reproduce from the repository root

Generate all conditions once, then point both fitting arms to the same SSD directory. The full profile defaults to replicate IDs 1–50. The comparison collects both arms into this single study report.

RESULTS="$HOME/bdynets-results/full"
TOOLS=GLS-paper/tools
Rscript "$TOOLS/study2-gls.R" --action=data --profile=full --output="$RESULTS"
Rscript "$TOOLS/study2-gls.R" --action=run --profile=full --output="$RESULTS"
Rscript "$TOOLS/study2-competitors.R" --action=run --profile=full --output="$RESULTS"
Rscript "$TOOLS/study2-gls.R" --action=report --profile=full --output="$RESULTS"

To check a single panel, use a separate output root, select --profile=smoke throughout and pass --scenario=mixed-dynamic to generation and both fitting arms. Each method records the input checksum in jobs.csv. The collector writes per-panel metrics in comparison.csv and matched differences in paired-replicates.csv.
