One-step vehicle count forecasts on US-101

This case uses the total vehicle count from five-minute mainline station records in District 4. Upstream and downstream ordering follows absolute postmile on northbound US-101. The source’s detector-observation percentage indicates where provider estimates can enter the reported totals.

Run scope. The smoke run contains 4 directed series and 288 time bins, with 48 final bins reserved for sequential forecasting. These scores check the workflow on the sample and are unsuitable for ranking methods in the manuscript.

Forecast comparison

Each method is scored on the same held-out counts. The log score integrates predictive uncertainty for models supplying a distribution. Larger log scores and smaller count errors indicate better forecasts. Interpret interval coverage with its width.

Reproduce from the repository root

Install the optional Python dependencies for Graph WaveNet as described in the GLS paper README. Set RESULTS to an external directory on the data or SSD volume. Preparation writes the count panel, source checksums and an exploratory plot. The application runner fits the training window, selects on validation, scores the held-out window and saves compact outputs. Report mode exports individual forecast cells and diagnostics. The final command rebuilds the executive report without fitting.

Rscript GLS-paper/applications/pems/prepare.R --output="$RESULTS/pems-prepared.rds"
Rscript GLS-paper/applications/run.R --action=run --profile=smoke --benchmarks=pnar1,pnar2,sa-pgss,graph-wavenet --input="$RESULTS/pems-prepared.rds" --output="$RESULTS/pems"
Rscript GLS-paper/applications/run.R --action=report --output="$RESULTS/pems"
Rscript GLS-paper/reports/render.R pems "$RESULTS/pems"
