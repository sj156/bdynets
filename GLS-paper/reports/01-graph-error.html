When the supplied graph contains wrong links

The graph-error design uses a PNAR generator with a known network average and a separate own lag. The experiment measures forecast error on the same count panel as increasing fractions of the supplied directed edges are replaced. The full and restricted GLS fits show the effect of admitting predictors outside the supplied graph.

Shared synthetic datasets

The GLS arm fits graph-informed, restricted and constant-affinity GLS. The competitor arm fits pooled PNAR. Both arms read the same saved counts and chronological split for each condition and replicate. The full study uses 50 independent replicates per condition.

Reproduce from the repository root

Generate all conditions once, then point both fitting arms to the same SSD directory. The full profile defaults to replicate IDs 1–50. The comparison collects both arms into this single study report.

RESULTS="$HOME/bdynets-results/full"
TOOLS=GLS-paper/tools
Rscript "$TOOLS/study1-gls.R" --action=data --profile=full --output="$RESULTS"
Rscript "$TOOLS/study1-gls.R" --action=run --profile=full --output="$RESULTS"
Rscript "$TOOLS/study1-competitors.R" --action=run --profile=full --output="$RESULTS"
Rscript "$TOOLS/study1-gls.R" --action=report --profile=full --output="$RESULTS"

To check a single panel, use a separate output root, select --profile=smoke throughout and pass --scenario=T100-error25 to generation and both fitting arms. Each method records the input checksum in jobs.csv. The collector writes per-panel metrics in comparison.csv and matched differences in paired-replicates.csv.
