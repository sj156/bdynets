# Current limitations

The initial 2026-10-15 core pilot stopped before 4000 iterations at an SE-W bandwidth proposal whose two normalized positive weights were about 2.24e-344 and 1.51e-379. The old guard and its original trajectories remain retained. This release implements an explicitly approved controlled binary64 approximation: retain logical support and all finite log weights, and allow only genuinely unrepresentable matrix entries to round to zero. There is no larger numerical cutoff, changed bandwidth prior, or NN edge deletion.

For nu=1, the positive regularizer a=2/kappa^2 bounds the effect of these entries on the normalized covariance, principal root and gate target. Frozen engineering residual checks compare the ordinary spectral result with an independent Cholesky-inverse covariance/root path. Checks raise errors on excess diagnostics; they do not turn numerical errors into MH rejections. This is not rigorous interval-certified MH: ordinary arithmetic and transcendental operations are not enclosed by outward-rounded intervals. Overflow, unrepresentable regularizers or excessive residuals can still stop a chain. Full core convergence and predictive comparisons remain unestablished.

The exact original failing proposal was replayed from its retained state/RNG. It passed the new diagnostics and was naturally rejected by the unchanged MH test, after which the transition completed. This single-step verification is not proof that the entire pilot finishes or mixes. The portable controller now allows valid peer chains to finish after a chain failure. It still does not automatically retry or resume arbitrary interrupted experiments.

The preceding public commit cb273d26810a563ffeddcb7f0d1556fe30f12d1d also overwrote C's own calibrated kappa prior center with the W reference. This release corrects that configuration: only Exp-W and SE-W share the fixed Exp-reference center; C retains its own binary-adjacency calibration (2.0000 on the 121-node path). Old C chains must not be reused as draws from the corrected prior. Original run records and failures are retained outside Git.
