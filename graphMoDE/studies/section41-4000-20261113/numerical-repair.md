# Finite-precision edge-weight evaluation for the 4000-sweep run

A newly authorized 4000-sweep run uses the unchanged Section 4.1 model, priors, K=10, proposal settings and four initial partitions. One original SE-W attempt stopped at sweep 196 when exp(-(distance/h)^2) rounded below double representability. Its output and failure record are retained; other original tasks continue.

The repair keeps the binary support and weight formula. It records the number of zero-rounded positive weights and a log-scale bound on the lost Laplacian norm, e <= 2 * edge_count * max_weight. With B = alpha I + L, alpha = 2 nu / kappa^2, covariance and precision are scalar powers of B. A conservative bound covering both relative operator perturbations is n max(nu,1) (e/alpha) ((norm(B)+e)/alpha)^max(nu,1). The native kernel keeps the exponent bound even below representable weights. The spectral wrapper requires this bound to be below machine epsilon/(64 n), and repeats the check for every kappa proposal. No bandwidth-prior cutoff or arbitrary weight threshold is introduced. Unsafe scales still fail closed.

In the finite-dimensional eigenbasis, divided differences of x^nu and x^(-nu) bound their Frechet derivatives. The factor n converts an entrywise derivative bound to an operator-norm bound; the exponent max(nu,1) conservatively covers both powers. The determinant perturbation is bounded by n nu log(1+e/alpha), also below this conservative bound. This is an explicit floating-point error check, not a claim of exact real arithmetic.

No extra sampling is used for these checks. When no edge weight underflows, the original numerical weight expressions and sampler RNG calls are unchanged.
