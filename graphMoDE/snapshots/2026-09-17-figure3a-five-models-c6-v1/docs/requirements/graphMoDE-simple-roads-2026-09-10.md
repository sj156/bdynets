## Figure 3(a)：必须按新定义实现，不能只改旧构造器的名称

- 准确名称：Intertwined-spiral road network。它是本文明确定义的二维道路构造，不声称“entangled Swiss roll”是具有唯一公式的标准数学对象。
- r(theta)=1/2+5*theta/(8*pi)，0<=theta<=4*pi；x_plus=r(theta)*(cos(theta),sin(theta))，x_minus=-x_plus。
- 每条臂两圈，内／外半径为 0.5／3；各取 theta_j=4*pi*j/59，j=0,...,59，共 60 个点，含端点。另有中心一个点，总计 n=121。
- 几何 ID 顺着唯一道路排列：1--60 是正臂从外到内，61 是中心，62--121 是负臂从内到外。物理边连接相邻 ID，共 120 段；中心两段各长 0.5。
- 两臂仅由 x 轴上的 [-0.5,0.5] 短直路连接。其余跨臂／跨圈近邻均不另加道路；曲线自身不相交。
- 臂内段长用 integral sqrt(r(u)^2+[5/(8*pi)]^2) du，不使用弦长。物理图是单连通分量的一条路径：两端度数 1，其余度数 2；不是新增分支拓扑。
- 图上蓝／橙仅区分道路臂，不是两类标签。生成剖面仍为五类，拟合容量十类。不能把臂身份直接当真实聚类。
- 图 (b) 保持 3 环／8 径向道路、25 路口＋每段两个内点共 121 个位置，所有环路交叉口可通行。
- 两图均保留物理最短路距离到对称化 q=4 近邻依赖图的流程。W/C 边支持相同，W 使用距离权重、C 使用二值权重；W/C 不是 heterogeneous/common a。
- 固定几何 ID 处理距离平局。拟合前整体随机重编号，坐标、响应和图一起搬动，不能以输入行号透露位置。几何检验先于响应生成。
- 两幅图是确定性设计示意，没有响应、真实分区或拟合结果。r2 的单臂四圈几何及其代码签名不能仅改标签冒充此 r4 几何（与 r3 相同）。

## 内部比较：保留 12 设置，不扩展成大网格

- 2 图 × 3 分区真相 × 2 档信号 = 12 设置；n=121、T=168、Ktrue=5、Kfit=Kmax=10；主响应 Poisson，全秩。
- 三种分区：道路距离 Voronoi、欧氏距离 Voronoi、保持道路分区类别规模的随机标签置换。五个种子从第一个几何 ID 开始，用对应距离的确定性最远点遍历生成，平局按 ID。两种 Voronoi 分区保证五个非空类别。
- 每个重复独立生成状态路径、响应及剖面到分区的随机对应；方法共享同一数据。不要丢弃偶然易分、难分或失败的重复。
- graphMoDE-W/C、EucMoDE 匹配类别截距和结构／独立项的自适应 gate；五种方法匹配动态专家、基函数、适用先验、容量与初始化规则。
- 比较问题分别是距离权重、道路与欧氏结构、有图与全局分配、utility prior 与 Potts 标签先验。这不是宣称五个独立原创方法，也不是所有先验完全相同的五种消融。
- 主指标 ARI；另报单位层面剖面误差、Bayesian co-clustering Brier error、时间与失败、占用类别数和碎片化。使用同一预声明代表分区，不能挑后验中 ARI 最高的样本。

## 代表模型选择与外部评价：执行规则已具体化

- 三池独立：信号／数值校准、代表选择、正式评价。先冻结各方法配置与 truth-blind 调参规则，再生成选择池；真标签只交离线评价器。
- 计划每设置 Rsel=20 个独立数据集，12 设置共 240 个，五方法共享。20 是规划数，不是精度保证，不是运行授权；资源驱动修订须在选择池开始前另行登记，不能看排名后追加数据。
- V_mhr=1 表示全部规定链／输出完整且通过下述诊断；否则为 0。数值失败、timeout、缺输出、诊断未通过均保留原因，不给失败拟合造 ARI。
- 每个方法必须在每个设置至少 18/20 有效才能进入资格集合 E。对每个设置取 E 中所有方法共同有效的重复集合 I_h；任一设置 |I_h|<16 或 E 为空，选择保持未决。不得临时删方法／场景来扩大交集。
- 对所有合格方法，在相同 I_h 上计算平均 ARI，再对 12 设置等权平均。明确这是“共同有效条件下”的比较，不是包含失败的无条件风险；同时报告所有尝试的失败率、资格集合、共同有效样本数及跨数据集配对不确定性。
- 落后最高分不超过 0.01 ARI 的方法进入实用平局集。依次取：最低设置有效率最高、总体有效率最高、共同有效集上 12 设置等权平均端到端成本最低；仍精确平局按 EucMoDE、graphMoDE-C、graphMoDE-W、MoDE、PottsMoDE 顺序。
- 成本在同硬件／线程配置下包括调参、分解、全部指定起点及拟合；全体尝试的总成本另报。18/20、16/20、0.01 是预定设计约定，不是已校准的错误概率。
- 只有一个合格候选时可作代表，但不得描述为准确度获胜。排名不稳定时如实报告；不预设 graphMoDE-W 胜出。
- 冻结唯一 M_star 后，正式内部比较与 M_star--STGNN 比较共享同一批新数据及所选模型的拟合，属于配对复用。被选择阶段排除的方法仍保留在正式内部比较及失败表中。
- 正式数据、场景、指标或竞争方法不能触发重新选代表；如选中非 graphMoDE，其外部结果归属于该真实方法。
- STGNN assignment head 容量十，原生 argmax 分区及固定平局规则；不强制五类，不将 soft score 称作 Bayesian posterior。共报 ARI、硬分区占用数、时间；仅在定义同一拟合量时比较剖面误差。
- STGNN 的来源版本、入口、结构、预处理、优化器、学习率／epoch／early stopping、重启选择、调参规则和预算均须实际登记及核验。缺 adapter 是实施阻塞，不能作为 STGNN 的科学失败或偷换替代方法。
- PNAR 仍是 Armillotta 与 Fokianos 的 Count Network Autoregression，只作预测，无原生标签／ARI，不能与 PNARM 混淆。

## Bayesian 有效拟合标准：只规定规则，不声称已经通过

- 选择和正式比较使用四条独立种子链；同方法／设置有相同预登记 warm-up 和保留长度，无结果驱动延长或仅保留好链。已有 D-032 短测试的两起点合同不受此改变。
- 全部四链需完成；不得绕过既有 exact PG 或数值保护。指标包含 log likelihood、Kocc、排序类别占比、存在时排序自由 guidance，以及几何 ID 1/31/61/91/121 在 t=1、84、t_end 的单位 log-mean；几何 ID 不等于置换后的输入行号。
- 非常数必需标量：rank-normalized split 和 folded Rhat 均<=1.01，bulk/tail ESS 均>=400（四链合计）。每对链的 PSM 在 n(n-1)/2 非重复单位对上的 RMS 差<=0.05。
- 各链完全相同的常数离散占用指标标记 uninformative，不伪造 Rhat/ESS；不同链常数不同则失败。其他必需非固定量的诊断未定义则无效；固定 a=0/1 不参与自由参数诊断。
- 同时保留状态／权重移动、proposal 和多起点图；上述必要条件不证明探索了所有模式。STGNN／PNAR 使用原生优化及 adapter 检查，不硬套 MCMC 阈值。
- timeout、基础设施失败、统计诊断失败、数值失败分别报告；不自动重试、换数据或放宽标准。代码身份／adapter 缺失在发布前阻塞，事后发现源码缺陷则隔离受影响批次并新登记，不能只重跑不利结果。
- 正式准确度按共同有效重复做配对汇总并说明条件性；选择池门槛不授权删除正式失败记录。

## 预测：两图上的同一分区／信号网格，另保留两个边界控制

- 两图使用 168 训练＋48 测试期，origins t=168,...,215。每个 origin 对 Y_1:t 全部可用前缀重新拟合 M_star 的分配／专家及 PNAR 系数；不是固定训练成员关系后用未定义的 state-only filter。超参数仅在初始 168 期内选择，测试期不再调优。
- 可用前一 origin 结果初始化一条指定 Bayesian 链，其余独立初始化；每次新目标都执行已登记 warm-up／保留长度及四链诊断。旧抽样不能直接当作新后验样本。全部 refit 成本计入时间；每 origin／整重复预算须在独立 timing 阶段冻结。若成本不可行，在评价开始前修订，不能只让慢方法少更新。
- 固定 M_star 与 PNAR 比较，不把其余四种内部方法全跑一遍；选中模型是聚类代表，不预先宣称预测最优。
- STGNN 保留为聚类比较，不是当前预测核心的必跑方法。其预测需另行验证能力、adapter 并登记为扩展，不因方法名字假设已有该能力。
- 共享剖面真相保留 2 图 × 3 分区 × 2 信号 = 12 设置、Ktrue=5、Kfit=10。保留基函数、初始形状、独立状态创新、信号幅度和 v；采用 lambda_kt=ell0*exp(s*c_kt)。
- ell0 在独立开发数据上事先选择，以获得大致相当的计数尺度；不能用任一正式路径的未来、测试或完整训练段来反向归一化早期状态。预登记计数尺度检查。
- 因此预测保留的是同一分区／信号网格，而不是主聚类的“全时段等累计均值”响应生成律；必须写明这个差别。
- 另在每个路网增加一个稳定线性 PNAR 生成设置，共两个控制，不再与三种标签真相、两档信号全面交叉。条件独立 Poisson 是简单有效生成案例。
- 非负 beta1、beta2 满足和小于 1；目标平稳平均计数 25 时，beta0=25*(1-beta1-beta2)。系数、初始化、burn-in 在开发阶段固定，有限 burn-in 另检验。
- PNAR 真相没有真实剖面类别，因此不报 ARI 或 Ktrue=5；拟合 profile mixture 仍为容量十。
- MAE 主、RMSE 辅，统一评价条件均值预测且不取整。Bayesian 预测为对 Z_i 与终端状态后验平均 exp(F'G theta + F'W_state F/2)；既积分分配／状态不确定性，又积分下一步 Gaussian 创新。不能用 exp(平均 log rate) 代替。PNAR 使用每个 origin 估计系数得到的 plug-in 条件均值。
- 中位数才最小化后验期望绝对损失；本方案声明比较“均值预测”的 MAE/RMSE，不声称 MAE 最优或按指标切换点预测。
- 每个完整重复在 121*48 个单位--origin 上计算 MAE 和 sqrt(mean squared error)。若任一 origin 失败，保留已完成输出，余下预测不可用，完整序列指标记 unavailable；不可默默缩短 horizon、填 0／无穷分数。报告全部尝试完成率和失败 origin，共同完整有效重复才用于配对准确度比较。
- 概率评分／覆盖率只用于已定义并验证的预测分布，区分 plug-in 与参数积分、边际与联合评分。
- 在网络滞后真相下允许 PNAR 获胜；graphMoDE 不模拟该冲击传播机制，也不能预知未宣布的外部 shock。“light-weight”须用精度与完整调参／更新成本支持。

## 生成律、K10 与 Potts：继续保留的边界

- 主聚类及 A/B 的全时段等总量归一化保留累计期望计数 T*25，但平移后的过去状态可能依赖未来创新。s^2*v*I 只匹配无条件增量协方差，不匹配完整独立创新 DLM 生成律；性能覆盖率不是 SBC 或采样正确性证明。
- T=168、平均计数 25 的每序列累计期望为 4200。弱／中等幅度及 v 须用独立 response-only oracle 校准，避免单凭响应就近乎完美分类；不能按 graphMoDE 优势挑信号。
- MoDE 每维 Dirichlet alpha=0.1、总浓度 1；graph/Euc gate 不另加稀疏 Dirichlet 先验。固定十类不能保证多余五类空置，不证明类别数估计一致性。
- PottsMoDE 适配 Green 与 Richardson (2002) 的分配先验并匹配动态专家，不完整复现其静态风险模型、随机 K、RJMCMC 或 beta 后验。原文已有距离加权相互作用。
- Potts beta=0 是十标签独立均匀先验，不等于稀疏 Dirichlet MoDE。beta 在包含 0 的短网格内用 truth-blind 响应验证选择，报告成本和敏感性。
- Potts 联合先验每条无向边计一次。固定 K、beta 时分区函数在标签更新中抵消，不代表更新 K 或 beta 时可省略。按附录合法逐点／图着色 Gibbs 更新，不能将相邻点按旧标签独立同步重抽。
- 保留十个专家及所有 gate 参数，空专家继续先验更新。报告 Kocc 后验、Pr(Kocc=5)、代表分区 Khat、过分／欠分、排序规模及规模<=4 的单位比例；不删小类或强制十对五参数配对。
- 单位拟合均值、区间和 co-clustering 使用标签不变汇总。Potts 同一剖面类可空间不连通，连通块数不是类别数。
- 出生／死亡和阈值穿越在同一标签索引下计算，纯重编号须零事件；label switching 本身不证明分区混合。
