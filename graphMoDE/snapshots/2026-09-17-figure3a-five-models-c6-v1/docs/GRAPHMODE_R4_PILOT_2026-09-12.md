# D-036：r4 最小四链测试预登记方案（等待用户确认后启动）

用户授权补齐四链执行／检查点／预算控制并局部冻结源码和预登记；本轮不运行。
这是一份新的开发测试合同，不是正式比较、信号／rho 校准、代表模型选择或论文结果。

## 固定方案

- 新协议 r4；中心连通双螺旋；单个新合成数据集；n=121、T=168、Ktrue=5、Kfit=10。
- 方法仅 graphMoDE-W，class-specific guidance，全秩 q4 加权图，nu=1、kappa=sqrt(2)、tau=s_b=1。
- 道路 Voronoi 真相；独立创新、计数及剖面／输入行置换。采用聚类全路径归一化，
  每类累计期望 4200；不是预测或 SBC 数据。
- 临时工程候选：幅度 .3、创新方差 .002、rho=2，匹配 W_state=.00018 I3；
  m0=(log25,0,0)、C0=diag(1,.5,.5)，guidance Beta(1,1)、logit proposal SD=.25，
  ESS bracket 上限1000。这些值不是已校准参数，不认定弱／中等信号难度，也不根据本轮表现调参。
- 四个 truth-blind 起点初始占用 1／3／7／10 类，各自独立种子打乱平衡标签；
  专家及 gate 中性初始化；不读取真标签作初始化或计算 ARI。
- 每链400步，warm-up200，thin1，保留200；每50步保存一个不可覆盖检查点。
  四链串行，数值库单线程。检查点供排错，不支持自动续跑。
- 每链子进程硬超时600秒（包括子进程检查／保存）；核心另有 sweep 边界预算。
  PG／输入／报告阶段各按300秒边界检查；全局3000秒边界预算。
  非链阶段的单个原生调用／保存可能使边界预算略有超出，不承诺精确秒级全局截止。
  超时／数值／基础设施失败保留检查点和原错误，停止启动余下链，无自动重试／延长。
- 先做独立 exact Devroye PG moment screen：五个 (b,z)=(1,0),(20,1),(500,5),
  (500,-5),(10000,5)，各2000值；均值 z-score<=6，方差相对误差<=.2。
  保留每组原样本；这不是分布正确性的证明。此阶段同样等待用户后续授权才执行。
- 四链全部完成后接 r4 原判据：两个 Rhat 各<=1.01、bulk/tail ESS 各>=400、
  六对 PSM RMS 各<=.05；一致常数占用仍为 uninformative。不会因为是短测试而放宽。
  短链很可能不通过；完成不是收敛。所有结果均无论文／正式放行权。

## 执行与身份

新入口 `scripts/graphmode-r4-pilot.R`，科学编排在 `R/graphmode4-pilot.R`。
旧 FFBS／MH、P2 保护及 r4 32 组受审计实现文件不修改。
每条链通过新的 r4 envelope 守卫，在新 R 进程中调用原 `graphmode_run`，
保留旧核心身份，同时把真实输入、方案、源码及结果绑定到外层 r4 注册身份。

preflight 要求所有依赖源码已在本地 Git 冻结并与工作目录相符、九个受审计核心文件
哈希不变、当前要求指纹匹配、实际加载函数结构匹配、R／包及递归依赖版本、R 数据库／共享库
指纹一致，以及单线程和 C locale。不要求把无关用户改动一起提交。
运行前后和阶段间检查源码／运行环境及外部输出树；目录消失不重建。
结果记录包含方案签名、四个完整原始诊断、所有保留状态、数值根保护证据及六对 PSM。

准备阶段只建立新的外部注册目录与 `pilot-registration.rds`，不生成数据，不创建 `run/`。
本次预定目录名 `graphmode-r4-four-chain-smoke-20260912-v1`，位于用户已有本地
`countDLM-local-results` 中；绝对路径、实际代码 commit/SHA、runtime 和签名写在外部 RDS。
用户若修改任一参数，需新版本／新注册目录；不得就地修改签名或复用已开始目录。

从仓库根目录可执行不含模拟的检查：

```sh
env LC_ALL=C /usr/local/bin/Rscript --vanilla scripts/graphmode-r4-pilot.R check
```

`prepare`／`preflight` 不授予启动权；`run ... --authorized` 只能在用户确认本方案后使用。
后续由助手打开终端运行，不需要用户手动输入；本轮不打开一个正在运行的模拟终端。
正式模拟、48个原点预测、STGNN／PNAR 适配不在这个小测试中。

本轮测试只使用固定数组、替代的 PG／生成器／子进程结果，验证调度和失败路径；
不会据此声称实际抽样或四链已通过。既有全仓库检查仍受旧审计绝对路径问题阻塞，
不修改旧报告或降低检查标准。

新增16组检查中包括冻结后新 R 子进程读取四份固定 envelope 的真实只读 preflight；
在源码尚未冻结时该项明确延后，其余调度测试使用替代结果。
