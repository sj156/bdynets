Beijing's unit is an all-lane entry rate, so time aggregation is a mean. D04's native total flow is a five-minute count, so twelve complete counts form an hourly station total. LA begins at hourly resolution. A PeMS display-link value averages available endpoints and does not create a source road measurement or sensor adjacency. CHP points establish reported starts only.

City-traffic-M volume and speed retain their native scales. Missing speed is marked before aggregation. The complete-day fill rule is recorded cell by cell; it does not change native coverage. The slowdown-volume index is derived from explicit full-history speed P90 and selected-day frame volume P95 calibration. No generic congestion threshold is inferred.

Divvy station IDs, departure timestamps, names and endpoint coordinates supply the OD input. The selected-day station register uses medians of valid paired coordinates. Unidentified or unlocated endpoints are excluded and counted. Spatial aggregation is not applied to the delivered primary input. The report derives hourly station OD and 1000 m spatial groups separately from the same retained day, preserving source clocks and group membership. Drawn arcs describe ordered endpoints, not travelled paths.

The small examples exclude the complete original archives. Full-source readers are implemented in the case `prepare.R`; City-traffic-M uses `read_parquet.py` for column-projected Parquet access. Native snapshots permit reproducible preparation without downloading the large originals. The small fixtures execute the same original-format readers in the reports. Each `data/raw/source-manifest.csv` identifies the parent source file, role, exact selection and byte identities; projected binary/configuration metadata and calibration/reference tables are labeled explicitly. All fixture source values come from the actual original files or the declared existing reference tables.

OpenStreetMap background context is attributed to OpenStreetMap contributors under ODbL and remains separate from all source measurements. Six runtime cache files accompany the examples in their `data/basemap-cache` directories. Matching verified requests can reuse this context without downloading it. Rendering a new extent or detail request, or a request whose cache is missing, requires network access. Existing report HTML embeds its figures for direct viewing.
